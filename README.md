# 🎮 Sudoku Game in Java

Welcome to **Sudoku Master**, a classic number puzzle game built entirely in Java! Whether you're a beginner or a seasoned Sudoku enthusiast, this project offers an engaging and challenging experience right from your terminal.

---

## 🌟 Features

- **Classic Sudoku Gameplay**: Enjoy the timeless logic-based number placement puzzle.
- **Customizable Difficulty Levels**: Choose between Easy, Medium, and Hard modes to match your skill level.
- **Interactive Console Interface**: A user-friendly text-based interface for seamless gameplay.
- **Error Checking**: Get instant feedback on invalid moves to help you stay on track.
- **Auto Solver (Optional)**: Stuck? Use the built-in solver to reveal the solution instantly.
- **Cross-Platform**: Runs on any system with Java installed.
